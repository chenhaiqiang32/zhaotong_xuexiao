# 空调设备接口文档（查询 / 控制）

控制设备唯一标识：`wg_mac` + `wg_qid`；列表展示主键：`dev_id`。

---

## 0 统一说明

### 0.1 请求路径

| 能力 | Method |  |
|------|--------|------------------|
| 查询设备状态 | GET | `/air-conditioner/devices` |
| 设备控制 | GET | `/air-conditioner/device/control` |

示例网关：`https://lot.nimt.edu.cn/api/air-conditioner/...`

### 0.2 统一响应结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | Number | HTTP/业务状态，成功一般为 `200` |
| `message` | String | 提示信息 |
| `result` | Object | 业务体，见下表 |
| `timestamp` | Number | 时间戳（有则返回） |

`result`（业务体）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | String | `"200"` 成功 |
| `message` | String | 业务提示 |
| `data` | Object / null | 业务数据 |

### 0.3 常用枚举

| 含义 | 字段 | 取值 |
|------|------|------|
| 在线 | `online` | **`88` = 在线**，其它为离线 |
| 开关 | `pwr` / `power` | `0` 关、`1` 开 |
| 模式 | `mode` | `1` 制热、`2` 制冷、`3` 送风 |
| 风速 | `fan` / `fan_set` | `1` 低、`2` 中、`3` 高、`4` 自动 |
| 温度 | `temp` / `temp_set` | 原始值 = 实际℃ × 10（如 `265` → 26.5℃） |
| 设备大类 | `ktType` | `1` 内机、`2` 主机、`3` 传感器 |

## 1 查询设备状态

### 1.1 接口描述

查询空调设备状态列表，支持按设备、空间、开关、类型等筛选，并支持分页。

### 1.2 请求概要

| 项目 | 值 |
|------|-----|
| URL | `GET https://lot.nimt.edu.cn/api/air-conditioner/devices` |
| 参数位置 | Query |

### 1.3 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `devId` | Integer | 否 | 设备 ID，精确筛选 |
| `liId` | String | 否 | 多个设备 ID，英文逗号分隔 |
| `roomId` | String | 否 | 房间 ID |
| `floorId` | String | 否 | 楼层 ID |
| `unitId` | String | 否 | 单元 / 组织 ID |
| `buildingId` | String | 否 | 楼栋 ID |
| `areaId` | String | 否 | 区域 ID |
| `devName` | String | 否 | 设备名称，模糊匹配 |
| `pid` | String | 否 | 设备类型标识 |
| `liPid` | String | 否 | 多个 pid，英文逗号分隔 |
| `wgMac` | String | 否 | 网关 MAC |
| `wgQid` | String | 否 | 设备子 ID |
| `pwr` | Integer | 否 | 开关：`0` 关、`1` 开 |
| `ktLock` | String | 否 | 锁定状态 |
| `ktType` | Integer | 否 | 设备大类：`1` 内机、`2` 主机、`3` 传感器 |
| `devStatus` | String | 否 | 在线状态文本（如「在线」「离线」） |
| `page` | Integer | 否 | 页码，从 **1** 开始 |
| `pageSize` | Integer | 否 | 每页条数 |

### 1.4 请求示例

按设备 ID：

```http
GET /api/air-conditioner/devices?devId=89531
```

分页 + 开机：

```http
GET /api/air-conditioner/devices?page=1&pageSize=20&pwr=1
```

按网关与子 ID：

```http
GET /api/air-conditioner/devices?wgMac=6543426f&wgQid=1
```

### 1.5 响应 `data`

| 字段 | 类型 | 说明 |
|------|------|------|
| `list` | Array | 设备列表，元素见 **1.6** |
| `page` | Integer | 当前页（有则返回） |
| `pageSize` | Integer | 每页条数（有则返回） |
| `total` | Integer | 总记录数（有则返回） |

### 1.6 `data.list[]` 设备字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `dev_id` | Number | 设备 ID（列表主键） |
| `online` | Number / null | **`88` = 在线** |
| `xh` | Number / null | 序号 / 信号相关 |
| `kt_lock` | Number / null | 锁定状态 |
| `pwr` | Number / null | `0` 关 / `1` 开 |
| `mode` | Number / null | `1` 制热 / `2` 制冷 / `3` 送风 |
| `fan` | Number / null | 当前风速 |
| `fan_set` | Number / null | 设定风速：`1` 低 / `2` 中 / `3` 高 / `4` 自动 |
| `sf_pwr` | Number / null | 附加电源状态 |
| `temp` | Number / null | 当前温度（℃×10） |
| `temp_set` | Number / null | 设定温度（℃×10） |
| `wg_id` | Number | 网关 ID |
| `wg_mac` | String | 网关 MAC（**控制必填**） |
| `wg_qid` | String | 设备子 ID（**控制必填**） |
| `dev_name` | String | 设备名称 |
| `unit_id` / `unit_name` | — | 组织单元 |
| `floor_id` / `floor_name` | — | 楼层 / 楼栋名 |
| `room_id` / `room_name` | — | 房间 |
| `area_id` / `area_name` | — | 区域 |
| `building_id` / `building_name` | — | 楼栋 |
| `pid` | String | 设备类型标识 |
| `dev_type_name` | String | 类型名称 |
| `err` | Number / null | 故障码 |
| `uptime` | String | 最近更新时间 |

## 2 设备控制

### 2.1 接口描述

对单台空调下发控制：开关、模式、风速、设定温度。  
设备定位必须使用 **`wgMac` + `wgQid`**（来自查询接口返回的 `wg_mac`、`wg_qid`）。

支持两种入参方式（二选一）：

1. **友好参数（推荐）**：`power` / `mode` / `fan` / `temp`
2. **透传参数**：`setType` + `setVal`

### 2.2 请求概要

| 项目 | 值 |
|------|-----|
| URL | `GET https://lot.nimt.edu.cn/api/air-conditioner/device/control` |
| 参数位置 | Query |
| 超时建议 | ≥ 60s（厂家控制可能较慢） |

### 2.3 请求参数

#### 设备定位（必填）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `wgMac` | String | **是** | 网关 MAC |
| `wgQid` | String | **是** | 设备子 ID |
| `pid` | String | 否 | 设备类型标识 |

#### 友好控制（推荐）

| 参数名 | 类型 | 必填 | 取值 | 说明 |
|--------|------|------|------|------|
| `power` | Integer | 否* | `0` 关 / `1` 开 | 开关机 |
| `mode` | Integer | 否* | `1` 制热 / `2` 制冷 / `3` 送风 | 运行模式（无除湿） |
| `fan` | Integer | 否* | `1` 低 / `2` 中 / `3` 高 / `4` 自动 | 风速 |
| `temp` | Integer | 否* | 建议 `16`–`30` | 设定温度（℃）；服务端自动 ×10 下发 |

\* 须提供 `setType+setVal`，或至少一个友好字段。

**组装规则：**

| 情况 | 行为 |
|------|------|
| 同时有 `setType`、`setVal` | 按透传下发，`ctrType` 默认 `set_one` |
| 仅 1 个友好字段 | `set_one`，对应 `pwr` / `mode` / `fan` / `temp` |
| 多个友好字段 | `set_many` + `many_ctr`，温度字段已 ×10 |
| 都未提供 | 报错 |

#### 透传控制

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `ctrType` | String | 否 | `set_one`（默认） / `set_many` |
| `setType` | String | 否* | `pwr` / `mode` / `fan` / `temp` / `many_ctr` 等 |
| `setVal` | String | 否* | 控制值；温度透传时需自行传 ×10 后的值 |

### 2.4 常用示例

关机：

```http
GET /api/air-conditioner/device/control?wgMac=6543426f&wgQid=1&power=0
```

开机：

```http
GET /api/air-conditioner/device/control?wgMac=6543426f&wgQid=1&power=1
```

设温度 26℃：

```http
GET /api/air-conditioner/device/control?wgMac=6543426f&wgQid=1&temp=26
```

设制冷：

```http
GET /api/air-conditioner/device/control?wgMac=6543426f&wgQid=1&mode=2
```

设自动风：

```http
GET /api/air-conditioner/device/control?wgMac=6543426f&wgQid=1&fan=4
```

组合（开机 + 制冷 + 26℃ + 自动风）：

```http
GET /api/air-conditioner/device/control?wgMac=6543426f&wgQid=1&power=1&mode=2&fan=4&temp=26
```

### 2.5 响应

| 字段 | 说明 |
|------|------|
| `result.code` | `"200"` 成功 |
| `result.message` | 如「控制成功」 |
| `result.data` | 厂家原始返回（结构不固定） |

成功示例：

```json
{
  "message": "success",
  "status": 200,
  "result": {
    "code": "200",
    "message": "控制成功",
    "data": {}
  }
}
```

失败示例：

```json
{
  "message": "success",
  "status": 200,
  "result": {
    "code": "500",
    "message": "控制失败: ...",
    "data": null
  }
}
```

## 3 设备唯一标识说明

| 用途 | 字段 | 说明 |
|------|------|------|
| 列表 / 筛选 | `dev_id` | 查询结果中的设备主键 |
| **控制（必用）** | `wg_mac` + `wg_qid` | 控制接口必填组合，缺一不可 |
| 辅助 | `pid` | 类型标识，控制时可带 |
