# IoT 设备搜索 / 点击 / 接口说明

本文档说明室外 `设备.glb` 图标设备的类型约定、搜索定位、点击拉近与 IoT 接口调用方式。  
旧版门锁（模型类型 `mensuo`）仍走 JetLinks 门锁接口，见 [门锁接口文档.md](./门锁接口文档.md)。

## 1. 流程概览

```
设备.glb 节点
  └─ 楼层节点（如 A01B001F03 / J32012500010103F01）
       └─ 类型节点（如 zhinengmensuo / menjin_xxx）
            └─ 设备节点（name = 设备编号）
                 ↓
Ground.buildDeviceIconsFromEquipmentModel → CSS2D 图标
                 ↓
点击图标 / 搜索定位 → enterIndoorAndFloor → focusDeviceIconLabel
                 ↓
按 deviceIconType 调取对应接口 → 信息牌展示
```

- **搜索入口**：页面右上角设备搜索面板，或 `Core.focusDeviceByTypeAndId(type, id)`
- **点击入口**：室内场景中设备 CSS2D 图标 `pointerup`
- **图标目录**：`public/icons/`（构建产物同步到站点 icons）

## 2. 设备类型与图标

| 类型 key（模型节点名前缀） | 中文名 | 图标文件 | 搜索用编号含义 |
|---|---|---|---|
| `zhinengmensuo` | 智能门锁 | `zhinengmensuo.png` | 门锁 ID（sn） |
| `LDXX` | 楼栋信息 | `LDXX.png` | 房间 ID（fjid） |
| `shuibiao1` | 水表一期 | `shuibiao.png` | 编号 propertyUid |
| `shuibiao2` | 水表二期 | `shuibiao.png` | 编号 propertyUid |
| `fangkeji` | 访客机 | `fangkeji.png` | 设备编码 |
| `guangbo` | 广播 | `guangbo.png` | 终端 ID |
| `jiankong` | 监控 | `jiankong.png` | 设备编码 |
| `menjin` | 门禁 | `menjin.png` | 门名称 / 设备编码 |
| `mensuo` | 智能门锁(旧) | `zhinengmensuo.png` | uuid（兼容旧模型） |

类型解析规则：模型类型组名按 `_` 取前缀，例如 `menjin_xxx` → `menjin`。

## 3. 接口一览（Base: `https://iot.niat.edu.cn`）

开发环境通过 `window.configs.iotApiBase = "/api/iot"` + Vite 代理访问：

| 本地路径前缀 | 代理目标 |
|---|---|
| `/api/iot/*` | `https://iot.niat.edu.cn/api/*` |

### 3.1 智能门锁 `zhinengmensuo`

- **URL**：`POST /api/lock-device/page`
- **参数**：

```json
{
  "pageNum": "1",
  "pageSize": "10",
  "sn": "181681773620"
}
```

- `sn`：点击图标得到的设备编号

### 3.2 楼栋信息 `LDXX`

- **URL**：`POST /api/api/roomBed/list`
- **参数**：

```json
{
  "jzwid": "JZ32012500010103",
  "fjid": "163"
}
```

- `jzwid`：当前楼栋 ID（由楼层键去掉 `Fxx` 得到，与室内 `buildingName` 一致）
- `fjid`：点击图标得到的房间 ID

### 3.3 水表一期 / 二期 `shuibiao1` / `shuibiao2`

- **URL**：`GET /api/energy/water-meters?propertyUid=xxxxxx`
- **参数**：`propertyUid` = 点击图标得到的编号

### 3.4 访客机 `fangkeji` / 监控 `jiankong`

当设备编号以 `_dahua` 结尾时：

- **URL**：`GET /api/dahua-device/detail/{xxxx}`
- **参数**：路径中的 `{xxxx}` = 图标编号去掉末尾 `_dahua`

若不以 `_dahua` 结尾，前端不发起请求，信息牌提示原因。

### 3.5 广播 `guangbo`

- **URL**：`GET /api/broadcast-terminal/terminals?endpointIdr=xxxxxx`
- **参数**：`endpointIdr` = 点击图标得到的终端 ID

### 3.6 门禁 `menjin`

**分支 A**：编号以 `_dahua` 结尾

- **URL**：`GET /api/dahua-device/detail/{xxxx}`（去掉 `_dahua`）

**分支 B**：其他情况

- **URL**：`POST /api/access-control/water-list/list`
- **参数**：

```json
{
  "pageNum": 1,
  "pageSize": 50,
  "doorName": "当前楼"
}
```

- `doorName`：当前楼栋名（与室内 `buildingName` 一致）

### 3.7 旧门锁 `mensuo`（兼容）

仍使用 JetLinks：

1. 初始化：`POST /api/smart-lock/page`（uuid → 门锁信息）
2. 点击后：`POST /api/smart-lock/pageOpenLog`（`lockName` + `apartmentName`）

详见 [门锁接口文档.md](./门锁接口文档.md)。

## 4. 前端代码位置

| 能力 | 文件 |
|---|---|
| 图标解析 / 索引 | `src/three/subsystem/Ground/index.js` → `buildDeviceIconsFromEquipmentModel` |
| 搜索定位 | `src/three/index.js` → `focusDeviceByTypeAndId` |
| 点击拉近 + 调接口 + 信息牌 | `src/three/subsystem/indoorSubsystem/index.js` → `focusDeviceIconLabel` / `showDeviceInfoForLabel` |
| IoT / 门锁 API 统一封装 | `src/api/iotDevice.js` |
| HTTP 实例（iot / smart-lock） | `src/api/iotHttp.js` |
| 搜索 UI | `index.html`（`#web3dDeviceSearchPanel`） |
| 配置 | `public/config.js` → `iotApiBase` / `smartLockApiBase` |
| 开发代理 | `vite.config.js` → `/api/iot`、`/api/smart-lock` |

## 5. 调用示例

```js
// 搜索并定位到智能门锁
await window.Core.focusDeviceByTypeAndId("zhinengmensuo", "181681773620");

// 定位楼栋信息点位（房间 ID）
await window.Core.focusDeviceByTypeAndId("LDXX", "163");

// 定位门禁（大华）
await window.Core.focusDeviceByTypeAndId("menjin", "xxxxx_dahua");
```

选中后会自动进入对应楼层、拉近视角、调用接口并弹出 CSS2D 信息牌。
